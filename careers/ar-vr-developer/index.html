Who it suits

Creative programmers excited by 3D worlds, interaction design, and new hardware.

How to become a AR

  1. Class 12 (any stream, Maths helpful)
  2. B.Tech/BCA/B.Sc in CS, Game Design, or Animation
  3. Learn Unity, C#, XR SDKs
  4. Build Demo Apps for Quest or Mobile AR
  5. Junior XR Developer Role

Skills you need

Unity / Unreal EngineIntermediate · Tool

The main engines for building XR experiences.

Where to learn: Unity Learn (free)

C# / C++Intermediate · Technical

Primary languages for interactive logic.

Where to learn: Microsoft C# Docs (free)
