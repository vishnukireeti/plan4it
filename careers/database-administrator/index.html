Who it suits

Careful, methodical students who like data structure, reliability, and troubleshooting.

How to become a Database Administrator (DBA)

  1. Class 12 (Maths/Science)
  2. B.Tech/BCA/B.Sc in CS or IT
  3. Learn SQL, DB Administration, Backups
  4. Practice on Cloud Free Tiers
  5. Junior DBA Role

Skills you need

SQLIntermediate · Technical

The base skill for every database role.

Where to learn: Mode SQL Tutorial (free)

Database Performance TuningIntermediate · Technical

Slow queries can cripple applications.

Where to learn: Use The Index, Luke (free)

Backup & RecoveryIntermediate · Domain

Protecting data from loss is the DBA's top duty.

Where to learn: PostgreSQL / Oracle Docs (free)

  • Oracle / PostgreSQL / MySQL
  • Cloud Databases

Useful certifications

  • Microsoft Azure Database Administrator Associate (DP-300)
  • AWS Certified Database – Specialty

Good things

  • Critical role with steady demand in banks and enterprises
  • Good salaries with experience
  • Path into cloud and data engineering

Hard things

  • Managed cloud databases are reducing some routine tasks
  • On-call duty for outages
