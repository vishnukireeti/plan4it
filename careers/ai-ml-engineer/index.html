Who it suits

Math-loving programmers who enjoy experimentation, research papers, and building intelligent systems.

How to become a AI

  1. Class 12 (Maths/Science)
  2. B.Tech CS/AI-ML then M.Tech or MS (optional)
  3. Learn Python, ML, Deep Learning, MLOps
  4. Kaggle Competitions & Research Projects
  5. Junior ML Engineer Role

Skills you need

PythonIntermediate · Technical

The default language of AI research and production ML.

Where to learn: CS50 Python / Kaggle Learn (free)

Machine LearningAdvanced · Technical

Core algorithms for prediction, classification, and recommendations.

Where to learn: Andrew Ng ML Specialization (Coursera)

Deep Learning (PyTorch / TensorFlow)Advanced · Tool

Frameworks used to build and train neural networks.

Where to learn: fast.ai / PyTorch Tutorials (free)

  • Linear Algebra & Statistics
  • MLOps

Good things

Hard things
