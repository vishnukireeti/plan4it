JNVST (Navodaya Entrance)

JNVST (Navodaya Entrance) is conducted by Navodaya Vidyalaya Samiti. It is used for admission to Admission to Navodaya Vidyalayas.

Open in Plan4it.coOfficial site: navodaya.gov.in
Conducted by
Navodaya Vidyalaya Samiti
Eligibility
Class 5 (for Class 6), Class 8 (for Class 9)
Courses
Admission to Navodaya Vidyalayas
Mode
Offline (OMR)
Difficulty
High

Preparation tip

Build concepts from NCERT textbooks and solve earlier papers for practice.
